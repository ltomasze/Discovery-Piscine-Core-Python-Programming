## How to Run the Scripts

Most scripts are designed to be run directly from the terminal.

1.  Make the file executable:
    ```bash
    chmod +x path/to/your/file.py
    ```
2.  Run the script:
    ```bash
    ./path/to/your/file.py [arguments...]
    ```
